# Anchangal — Five Stones

A polished React/Vite browser game inspired by the traditional South Indian game Anchangal (Five Stones).

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Included

- Main menu
- Game setup
- 8-stage progression
- Interactive toss / pickup / catch loop
- Stage-specific action controls
- Mistake and score handling
- Stage resume behavior
- Responsive desktop/mobile UI
- Pause menu
- Sound toggle persistence
- LocalStorage best score
- Rules screen
- Victory screen

## Controls

1. Click a stone to toss it.
2. While it is airborne, click other stones to pick them up.
3. Click `CATCH` or `CATCH / COMPLETE ACTION`.
4. For stages 4–8, use `PERFORM STAGE ACTION` for the special stage behavior.

This is a front-end game implementation; no backend is required.
