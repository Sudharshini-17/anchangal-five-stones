## 🌟 Game Features

- **8-Stage Progression**: Complete all traditional game stages from *Ones* to *Final Challenge*.
- **Single & Multiplayer**: Play solo or with up to 4 players on a single device.
- **Interactive Controls**: Toss stones, pick up ground stones, and make precision catches.
- **Sound Effects & Settings**: Toggle audio, track high scores, and view the leaderboard.
- **Pause & Resume**: Restart stages or resume where you left off.
- **Standalone Windows Executable**: Runs locally on Windows with offline support.

---

## 🎯 How to Play & Controls

1. **Toss**: Click a stone to toss it into the air.
2. **Pickup**: While it is airborne, click the required number of ground stones to pick them up.
3. **Catch**: Click `CATCH` or `CATCH / COMPLETE ACTION` before the airborne stone lands.
4. **Special Stage Actions**: For stages 4–8, use `PERFORM STAGE ACTION` for stage-specific challenges.

## 🛠️ Local Development & Build

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Run Locally
```bash
npm install
npm run dev
```

### Run Electron Desktop App
```bash
npm run electron
```

### Build Production Windows .exe
```bash
npm run dist
```

The output executables will be generated in the `release/` folder.
